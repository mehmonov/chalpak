# O'rnatish

Ushbu qo'llanma Chalpak veb-freymvorkini o'rnatish bo'yicha ko'rsatmalarni taqdim etadi.

## O'rnatish Imkoniyatlari

Chalpakni o'rnatish va undan foydalanishni boshlashning bir necha yo'li mavjud:

-   **Pip yordamida (Tavsiya etiladi):** Chalpakni o'rnatishning eng oson va keng tarqalgan usuli - bu Python paket o'rnatuvchisi bo'lgan `pip` orqali.
-   **Repozitoriyani klonlash:** Ishlab chiqish uchun yoki eng so'nggi (ehtimol beqaror) funksiyalarga kirish uchun siz Chalpak repozitoriyasini GitHub'dan klonlashingiz mumkin.
-   **Loyihalar shablonidan foydalanish (Tez orada):** Biz oldindan sozlagan tuzilishga ega yangi Chalpak loyihasini tezda ishga tushirish uchun foydalanishingiz mumkin bo'lgan loyiha shablonini taqdim etish ustida ishlamoqdamiz.

## 1-usul: Pip orqali o'rnatish (Tavsiya etiladi)

**1-qadam: Chalpakni o'rnating**

Chalpakni `pip` yordamida o'rnating:

```bash
pip install chalpak
```
**2-qadam: O'rnatishni tekshiring**

Chalpakning to'g'ri o'rnatilganligini versiyasini tekshirish orqali tasdiqlang:

```bash
chalpak --version
```
Siz konsolda Chalpakning o'rnatilgan versiyasini ko'rishingiz kerak.

## 2-usul: Repozitoriyani klonlash (Ishlab chiqish uchun)

Agar siz Chalpakni ishlab chiqishga hissa qo'shmoqchi bo'lsangiz yoki eng so'nggi (ehtimol beqaror) versiyaga ehtiyoj sezsangiz, ushbu usuldan foydalaning.

**1-qadam: Chalpak repozitoriyasini klonlang**

Chalpak repozitoriyasini GitHub'dan klonlang:

```bash
git clone https://github.com/mehmonov/chalpak
```
**2-qadam: Loyiha katalogiga o'ting**

Joriy katalogingizni yangi klonlangan Chalpak papkasiga o'zgartiring:

```bash
cd chalpak
```

**3-qadam: Virtual muhit yarating**

Loyiha bog'liqliklarini ajratish uchun virtual muhit yaratish tavsiya etiladi:

```bash
# Windowsda
python -m venv venv
# macOS/Linuxda
python3 -m venv venv
```
**4-qadam: Virtual muhitni faollashtiring**

Virtual muhitni faollashtiring:

```bash
# Windowsda
venv\Scripts\activate
# macOS/Linuxda
source venv/bin/activate
```

## 3-usul: Loyiha shablonidan foydalanish (Tez orada)

    Eslatma: Bu funksiya hali mavjud emas, ammo kelajakdagi relizlar uchun rejalashtirilgan.

Biz yangi Chalpak ilovalarini tezda ishga tushirishni soddalashtirish uchun loyiha shablonini yaratish ustida ishlamoqdamiz. Ushbu shablon asosiy loyiha tuzilishi, misol kod va konfiguratsiyani taqdim etadi.


## Muammolarni bartaraf etish

O'rnatish jarayonida biron bir muammoga duch kelsangiz, quyidagilarni tekshiring:

-   Python 3.7 yoki undan yuqori versiyasi o'rnatilganligiga ishonch hosil qiling.
-   `pip` ning yangilanganligiga ishonch hosil qiling (`pip install --upgrade pip`).
-   Agar virtual muhitdan foydalanayotgan bo'lsangiz, uning faollashtirilganligini tekshiring.
-   Umumiy muammolarni hal qilish uchun Chalpak repozitoriyasining muammolar kuzatuvchisi yoki jamoa forumlariga murojaat qiling.

Biron bir muammoga duch kelsangiz, biz yordam berishga tayyormiz. Chalpak bilan muvaffaqiyatli kod yozing!
