## Loyiha Tuzilishiga Umumiy Nuqtai Nazar

### app

Bu papka Next.js uchun asosiy ilova kodini o'z ichiga oladi, u joylashuvlar, marshrutlash va maxsus kontent sahifalarini boshqaradi. U `docs` va `blog` bo'limlarini qo'llab-quvvatlash uchun tashkil etilgan bo'lib, har bir bo'lim uchun maxsus sahifalar va joylashuvlar mavjud.

```
app                         // Asosiy Next.js ilova papkasi
├── page.tsx                // Bosh sahifa - ilovaning asosiy kirish nuqtasi, asosiy kontentni namoyish etadi
├── layout.tsx              // Asosiy joylashuv fayli, global navigatsiya va futerni qo'llaydi
├── blog
│   ├── page.tsx            // Blog ro'yxati sahifasi, barcha blog postlarini sarlavhalar, sanalar va qisqa tavsiflar bilan ko'rsatadi
│   └── [slug]
│       └── page.tsx        // Dinamik blog posti sahifasi, alohida postlarni boy kontent bilan ko'rish uchun
└── docs
    ├── layout.tsx          // Yon panelli hujjatlar joylashuvi, hujjat sahifalari bo'ylab oson navigatsiyani ta'minlaydi
    └── [[...slug]]         // Ichki hujjat sahifalarini boshqarish uchun barcha marshrutlarni qamrab oluvchi marshrut, moslashuvchan hujjat tuzilishini ta'minlaydi
```

### components

Bu papka butun loyiha bo'ylab ishlatiladigan barcha qayta ishlatiladigan komponentlarni o'z ichiga oladi. U komponentlarni kategoriyalash uchun tuzilgan bo'lib, UI elementlari, Markdown sozlamalari va navigatsiyani topish va boshqarishni osonlashtiradi.

```
components                    // Qayta ishlatiladigan komponentlar
├── ui                        // ShadCN komponentlari, tugmalar, formalar va modallar kabi standartlashtirilgan UI elementlarini o'z ichiga oladi
├── markdown                  // Boy Markdown kontentini ko'rsatish uchun maxsus Markdown komponentlari
│   ├── CodeBlock.tsx         // Sintaksisni ajratib ko'rsatuvchi kod bloklarini ko'rsatish uchun komponent
│   ├── Image.tsx             // Markdown'da responsiv rasmlarni boshqarish uchun komponent
│   └── Table.tsx             // Izchil uslubga ega jadvallarni ko'rsatish uchun komponent
└── navbar.tsx                // Sayt sarlavhasi uchun asosiy navigatsiya komponenti, havolalarni va responsiv xatti-harakatni boshqaradi
```

### styles

Bu papka global va komponentga xos CSS fayllarini o'z ichiga oladi, bu loyiha bo'ylab uslublar izchilligini va sozlashlarni ta'minlaydi.

```
styles                        // CSS fayllari
├── globals.css               // Global CSS fayli, Tailwind asosini, yordamchi dasturlarni va maxsus global uslublarni o'z ichiga oladi
├── syntax.css                // Sintaksisni ajratib ko'rsatish uslublari, sayt bo'ylab izchil kod bloki ko'rinishini ta'minlaydi
└── overrides.css             // Maxsus komponent yoki plagin standartlarini bekor qiluvchi qo'shimcha maxsus uslublar
```

### contents

Bu papka hujjatlar va blog bo'limlari uchun barcha Markdown kontentini saqlaydi, kontent turi bo'yicha aniq tashkil etilgan. Har bir Markdown fayli bitta kontent qismini ifodalaydi, metadata uchun frontmatter ishlatiladi.

```
contents                      // Bloglar va hujjatlar uchun Markdown kontenti
├── docs                      // Hujjatlar kontenti, ichki bo'limlar va sahifalarni qo'llab-quvvatlash uchun tuzilgan
│   ├── getting-started.md    // Yangi foydalanuvchilar uchun kirish qo'llanmasi
│   ├── api-reference.md      // Batafsil endpoint tavsiflari bilan API hujjatlari
│   └── tutorials             // Qo'llanma uslubidagi kontent uchun ichki papka
│       └── tutorial-1.md     // Muayyan mavzu bo'yicha bosqichma-bosqich qo'llanma
└── blogs                     // Blog kontenti, post bo'yicha tashkil etilgan
    ├── intro-to-project.md   // Loyihani va uning maqsadlarini tanishtiruvchi blog posti
    └── dev-updates.md        // So'nggi ishlab chiqish yangilanishlari va yangi funksiyalar haqida post
```

### public

Bu papka barcha statik aktivlarni, masalan, rasmlar, videolar, shriftlar va ikonkalarni saqlaydi. Bu fayllar URL orqali to'g'ridan-to'g'ri kirish mumkin, shuning uchun bu yerda sezgir yoki shaxsiy kontentdan qochish muhimdir.

```
public                        // Ommaviy kirish mumkin bo'lgan aktivlar
├── images                    // Rasm aktivlari, ilovaning turli qismlarida ishlatiladi
│   ├── logo.png              // Brending uchun loyiha logotipi
│   └── banner.jpg            // Bosh sahifa uchun banner rasmi
├── icons                     // Ilova uchun SVG ikonkalari
└── videos                    // Media kontenti uchun video fayllar, agar mavjud bo'lsa
```

### lib

Bu papka ilova bo'ylab ishlatiladigan yordamchi funksiyalar va yordamchi dasturlarni o'z ichiga oladi, masalan, Markdown tahlili va marshrutlash mantiqi. Bu yordamchi dasturlar umumiy funksionallikni ajratish orqali kod bazasini toza va tartibli saqlashga yordam beradi.

```
lib                           // Yordamchi yoki yordamchi funksiyalar
├── markdown.ts               // Markdown tahlili mantiqi, Markdownni HTMLga o'tkazadi va maxsus komponentlarni qo'shadi
├── routes-config.ts          // Hujjatlar uchun marshrutlash konfiguratsiyasi, URL'larni dinamik marshrutlash uchun kontent fayllariga bog'laydi
└── utils.tsx                 // Ilova bo'ylab ishlatiladigan umumiy yordamchi funksiyalar, masalan, ma'lumotlarni formatlash va validatsiya yordamchilari
```

### Qo'shimcha

- **`package.json`**: Loyiha haqidagi metadata, bog'liqliklar va ilovani qurish va ishga tushirish uchun skriptlarni o'z ichiga oladi.
- **`tailwind.config.ts`**: Tailwind CSSni sozlaydi, bu loyihaga xos ranglar, shriftlar va responsiv nuqtalarni sozlash imkonini beradi.

Ushbu tuzilma loyihangizni kengaytirilish va saqlanishni qo'llab-quvvatlaydigan tarzda tashkil etadi, bu esa ilovaning turli bo'limlarida navigatsiya qilish va ishlashni osonlashtiradi.
