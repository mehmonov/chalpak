# Tezkor Boshlash Qo'llanmasi

Ushbu qo'llanma sizga Chalpak freymvorkini o'rnatish va birinchi "Salom, Dunyo!" ilovangizni yaratishda yordam beradi.

## 1. O'rnatish

Chalpakni `pip` paket menejeri yordamida osongina o'rnatishingiz mumkin. Terminalingizda quyidagi buyruqni bajaring:

```bash
pip install chalpak
```

Bu buyruq Chalpak va uning ishlashi uchun zarur bo'lgan barcha kutubxonalarni (`aiohttp`, `Jinja2` va boshqalar) o'rnatadi.

## 2. Birinchi Ilovangiz

Endi keling, oddiy veb-ilova yaratamiz. O'zingizga qulay bo'lgan joyda `main.py` nomli fayl yarating va unga quyidagi kodni yozing:

```python
from chalpak.app import Chalpak
from chalpak.response import JSONResponse

# Chalpak ilovasini yaratamiz
app = Chalpak()

# Marshrut (route) va uning ishlovchisini (handler) belgilaymiz
@app.get("/salom/{name}")
async def index(request, name):
    return JSONResponse({"message": f"Salom, {name}!"})

# Ilovani ishga tushirish (agar fayl to'g'ridan-to'g'ri ishga tushirilsa)
if __name__ == "__main__":
    app.run()
```

Ushbu kodda nimalar bo'layotganini ko'rib chiqamiz:

1.  `Chalpak` klassi import qilinadi va uning nusxasi (`app`) yaratiladi.
2.  `@app.get("/salom/{name}")` dekoratori `index` funksiyasini `GET` so'rovlari uchun `/salom/{name}` yo'liga bog'laydi. `{name}` bu dinamik segment bo'lib, URL manzilidan olinadigan o'zgaruvchini bildiradi.
3.  `index` funksiyasi `request` obyekti va URL'dan olingan `name` parametrini qabul qiladi.
4.  Funksiya `JSONResponse` obyektini qaytaradi, bu esa `{"message": "Salom, {name}!"}` JSON javobini hosil qiladi.
5.  `app.run()` metodi veb-serverni ishga tushiradi.

## 3. Ilovani Ishga Tushirish

Ilovani ishga tushirish uchun `jurigged` dan foydalanish tavsiya etiladi. Bu kodga o'zgartirish kiritganingizda serverni avtomatik ravishda qayta ishga tushiradi.

Terminalda quyidagi buyruqni bajaring:

```bash
jurigged -v main.py
```

Server ishga tushganidan so'ng, siz quyidagi kabi xabarni ko'rasiz:

```
======== Running on http://127.0.0.1:6767 ========
(Press CTRL+C to quit)
```

## 4. Sinab Ko'rish

Endi veb-brauzeringizni oching va quyidagi manzilga o'ting:

[http://127.0.0.1:6767/salom/dunyo](http://127.0.0.1:6767/salom/dunyo)

Siz brauzerda quyidagi JSON javobini ko'rishingiz kerak:

```json
{
  "message": "Salom, dunyo!"
}
```

Tabriklaymiz! Siz Chalpak yordamida o'zingizning birinchi veb-ilovangizni muvaffaqiyatli yaratdingiz va ishga tushirdingiz.
